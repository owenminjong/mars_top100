# 마스 TOP100 — 한국투자증권 KIS

Windows에서 사용자 본인의 KIS 키로 시세를 조회하는 Tkinter 프로그램입니다. 조회·정렬·전거래일 비교·저장은 모두 사용자 PC에서 처리하며 운영 서버는 필요하지 않습니다. 주문 기능은 없습니다.

## 사용자 설정과 실행

1. [한국투자증권 KIS Developers](https://apiportal.koreainvestment.com/intro)에서 Open API 서비스를 신청하고 **실전투자용 App Key와 App Secret**을 발급받습니다.
2. `마스_TOP100.exe`를 실행합니다. Python 설치는 필요 없습니다.
3. 최초 설정 창에 두 값을 입력하고 **연결 확인 및 사용**을 누릅니다. 기본은 이번 실행에서만 사용하며 **키·토큰을 파일에 저장하지 않습니다.** 계좌번호·HTS ID는 입력하지 않습니다.
4. 저장을 원하면 **이 PC에 비밀번호로 잠가 저장**을 선택하고 12~128자의 고유한 잠금 비밀번호를 두 번 입력하세요. 다음 실행에는 **저장된 키 잠금 해제**가 필요합니다. 비밀번호는 저장하지 않으며, 분실 시 키를 다시 입력해야 합니다.
5. 이전 버전의 키는 자동으로 읽지 않습니다. **기존 키를 위에서 선택한 방식으로 전환**을 이용하세요. 저장을 끄고 전환하면 기존 키 파일을 삭제하고 이번 실행에서만 사용합니다. 저장을 선택하면 비밀번호 보호 형식으로 교체합니다.
6. **키 잠금**은 조회를 중지하고 작업 종료 후 앱의 키 사용 상태를 해제합니다. 저장한 키는 비밀번호로 해제하고, 저장하지 않은 키는 다시 입력합니다. 서버의 키·토큰을 폐기하는 동작은 아닙니다.

모의투자 키는 지원하지 않습니다. 키는 채팅·소스 코드·배포 파일에 넣지 마세요. 다른 PC나 다른 Windows 계정에서는 해당 사용자의 키를 다시 입력합니다.

## 유지된 기능과 달라진 점

- 코스피·코스닥·전체 TOP100, 미국 TOP100, 미국 급등주 탭을 제공합니다. 국내 탭은 날짜 선택·열 정렬·중지·전거래일 비교를 지원하며 거래대금/거래량 순위를 선택할 수 있습니다.
- 공식 종목 마스터의 주식·우선주·리츠·외국주식 등을 대상으로, 멀티종목 시세 API를 **30종목씩 전부 조회**하고 로컬에서 TOP100을 계산합니다. ETF·ETN·ELW 등은 대상에서 제외합니다.
- 오늘 조회는 **전체 수집 완료 후 5초 뒤** 다시 시작합니다. 실제 한 주기는 통신 속도·종목 수·호출 제한에 따라 더 길어집니다. 같은 순간의 일괄 시세가 아니며 화면에 수집 시간 구간·진행 상황을 표시합니다. 일부 응답 누락 시 불완전한 순위임을 표시합니다.
- 장 시작 전·휴장일은 KIS 지수 일봉에서 확인한 최근 거래일의 일봉을 사용합니다. 과거 날짜를 직접 선택했을 때 휴장일이면 다른 날짜로 대체하지 않고 안내합니다. 주말에는 최초 조회 후 자동 접속을 멈춥니다.
- 과거 순위는 **현재 상장 종목과 현재 시장 구분**을 사용합니다. 상장폐지·시장 이전 때문에 당시 실제 전체시장 TOP100과 다를 수 있습니다. 업종도 현재 KIS 분류입니다.
- 일봉 데이터 수집은 작업자 4개를 사용하지만, KIS REST 요청은 앱 전체에서 한 번에 하나씩 보내고 요청 간격을 최소 0.2초로 둡니다. 한 종목을 조회할 때 주변 **90일(달력 날짜) 구간**을 함께 받아 전거래일 비교와 인접 날짜 조회에 재사용합니다. 오늘 데이터는 저장하지 않습니다.
- 저장된 날짜는 종목마다 DB를 열지 않고 한 번에 읽습니다. 새 자료는 최대 24종목씩 묶어 저장하며 중지 시 받은 자료도 보존합니다. 비교 자료를 먼저 표시한 뒤 업종을 보충합니다.
- KIS 기간별 일봉 API는 **한 종목씩** 요청해야 합니다. 모든 종목의 전일 일봉을 한 번의 API 요청으로 받는 기능은 사용하지 않습니다. 미수집 날짜의 전체 시장 최초 조회는 여전히 수분 걸릴 수 있습니다. 거래대금은 실제 응답 값(원)을 사용하며 종가×거래량으로 추정하지 않습니다.

## 부가기능: 미국주식 TOP100 탭

코스피·코스닥·전체 탭 오른쪽의 **미국 TOP100** 탭은 KIS `해외주식 거래대금순위`(`HHDFS76320010`, 거래량 기준 선택 시 `거래량순위` `HHDFS76310010`)를 나스닥(NAS)·뉴욕(NYS)·아멕스(AMS) 순서로 한 번씩 조회하고, 이 PC에서 합산해 TOP100을 만듭니다. 거래소당 3회 호출이며 기존 KIS 공용 호출 제한·토큰·재시도를 그대로 사용합니다.

- 금액은 **달러**이며 `억 달러`/`조 달러`로 표시합니다. 거래대금은 응답의 `tamt` 값을 그대로 쓰고 현재가×거래량으로 추정하지 않습니다. 값이 없는 행은 0으로 바꾸지 않고 건너뛰며 순위 불완전으로 표시합니다.
- 미국 순위 API는 **날짜를 받지 않으므로** 항상 최신 순위입니다. 조회 날짜 입력·오늘/어제 버튼은 미국 탭에 영향을 주지 않습니다.
- 국내와 같은 열을 표시합니다. 시가·전거래일 거래대금·거래량은 KIS 종목별 일봉을 통해 종목당 1회씩 순차 보충하며, 한 번의 조회에서 최대 20종목을 처리합니다. 보충 중에는 `조회 중`으로 나타나고 다음 자동 갱신에서 이어서 처리합니다. 프리마켓에는 당일 정규장 시가가 아직 없으므로 `정규장 전`으로 표시합니다. 거래대금순위 API 값이 없을 때는 현재가×거래량 추정치를 사용합니다. 미국 업종은 KIS API에서 제공하지 않아 `KIS 미제공`으로 표시합니다. 종목 클릭 분봉 비교와 외국인·기관 수급은 국내 종목 전용입니다.
- 응답에 종목 구분이 없어 **ETF·ETN도 포함**됩니다(SPY·QQQ 등).
- 자동 갱신은 미국 동부시간 평일 03:00~20:00에 조회 완료 후 약 2초 뒤 다시 시작하며, 그 밖의 평일에는 약 60초 간격입니다. 한국시간 17시가 미국 서머타임/표준시간에 따라 프리마켓 시작 전후로 달라지는 점을 고려해 03시부터 확인합니다. 미국 주말에는 순위 갱신을 멈춥니다. 미국 공휴일은 판단하지 않습니다. 서머타임은 PC에 시간대 자료가 없어도 동작하도록 직접 계산합니다. 급등주 상세값이 남아 있으면 장외·주말에도 약 2초 간격으로 보충하고 완료되면 멈춥니다.
- 한 거래소의 응답이 100건보다 적고 그 최저값이 합산 TOP100 경계보다 크면 일부 종목이 빠졌을 수 있다고 표시합니다. 실시간/지연 시세 여부는 KIS 계정의 해외시세 신청 상태에 따릅니다.

## 부가기능: 미국 급등주

**미국 급등주** 탭은 KIS 해외주식 상승율/하락율 순위(`HHDFS76290000`)에서 나스닥·뉴욕·아멕스의 당일 상승률 상위 종목을 가져와 상승률순으로 합칩니다. 현재 거래대금은 거래대금 순위 API 값을 우선 사용하고 없으면 **현재가×누적거래량 추정치**로 표시합니다. 전 거래일 거래대금은 전일 거래대금 순위와 종목별 일봉을 보충해 채우며, API 거래대금이 없으면 종가×거래량 추정치를 씁니다. 새로 나타난 종목은 한 번의 조회에서 최대 100종목까지 일봉을 보충하며, 완료 전에는 `조회 중`으로 나타납니다. 미국 동부시간 평일 03:00~20:00 사이 조회가 끝난 뒤 약 2초 후 순위 조회를 다시 시작하고, 그 밖의 평일에는 약 60초 간격으로 갱신합니다. 주말에도 누락된 상세값이 있으면 약 2초 간격으로 보충하고, 채우면 멈춥니다. REST 순위 조회라 체결 단위 실시간 푸시는 아니며 KIS 시세 신청과 응답 시점에 따라 지연될 수 있습니다. ETF 등 종목 유형은 API 응답에서 구분되지 않아 포함될 수 있습니다.

## 부가기능: 전 거래일 동시간 누적 거래대금

과거 조회가 API 호출 제한이나 일시적 통신 오류로 중단되면 남은 대기시간을 표시하고 **같은 날짜·시장·순위 기준으로 자동 재개**합니다. 이미 저장된 과거 일봉은 재사용하고 누락된 종목을 조회합니다. 연속 실패 시 대기를 늘리며, 서버가 지정한 대기시간을 지킵니다. 주말에도 중단된 과거 조회는 이어가되 완료 후에는 반복하지 않습니다. **중지·날짜 변경·키 설정·앱 종료 시 예약된 자동 재개를 취소**합니다. 잘못된 날짜 등 재시도로 해결되지 않는 오류는 자동 반복하지 않습니다.

메인 화면은 기존 표·탭·자동 갱신을 유지합니다. **종목 행을 한 번 클릭**하면 해당 종목의 분봉 비교 창이 바로 열립니다. 다른 종목을 클릭하면 같은 창이 해당 종목으로 전환됩니다.

1. **클릭한 한 종목만** 비교값과 그래프를 조회합니다. 오늘 목록에서 클릭하면 **최신 · 매분 갱신**으로 열리고, 과거 날짜의 목록이면 그 날짜의 15:30을 기준으로 열립니다. 전체 종목의 분봉을 미리 조회하지 않습니다.
2. **전 거래일 그래프는 장 마감까지 전체를 표시**하고, 기준일 그래프는 조회 시각까지 표시합니다. 오늘 최신 모드는 완료된 분이 바뀔 때 오늘 곡선을 연장합니다. 초 단위 체결 중계가 아닌 **완료 1분봉 기준 갱신**입니다. 중지 버튼으로 자동 갱신을 멈춥니다.
3. **직접 지정**에서 날짜(`YYYY-MM-DD`)와 완료 분봉 시각(`HH:MM`)을 입력하고 **선택 종목 조회**를 누르면 과거 시점도 비교합니다. KST 기준이며 직접 지정한 **10:30은 10:30분 전체를 포함**합니다. 최신 모드는 10:30:45에 조회하면 10:29분까지 비교합니다. 진행 중인 분·미래 분은 거부합니다.
4. 위쪽 표는 기준일 누적, **전 거래일의 같은 시각까지의 누적**, 증가액, 증가율을 표시합니다. 전 거래일 그래프가 전체 표시되어도 이 표의 비교 분모는 동시간 누적입니다. 메인 화면의 기존 하루 전체 비교와 정렬은 유지합니다.
5. 그래프 표시 간격은 **5분/15분**으로 전환할 수 있으며 최신 도달 시각도 포함합니다. 기준일은 빨간 실선, 전 거래일은 파란 점선입니다. 점 위에 마우스를 올리면 금액과 증가율이 보입니다. 금액은 **1조 2,818억 원**, **7,980.3억 원**처럼 표시하고 축도 억·조 단위로 표시합니다. 화면 표시만 반올림하며 계산은 원 단위 정수로 합니다.

계산 기준:

- KIS `주식일별분봉조회` (`FHKST03010230`)의 **`output2.acml_tr_pbmn`은 누적 거래대금(원)**입니다. 해당 분봉의 누적값을 그대로 사용합니다. 분봉 누적값을 더하거나 `종가×체결량`으로 추정하지 않습니다. 개별 구간 거래대금이 필요하면 같은 날짜의 구간 끝·시작 누적값 차이를 사용해야 합니다. 여기서 5분/15분은 **누적값을 표시하는 간격**이며 구간 거래대금을 뜻하지 않습니다.
- 양쪽 모두 **KRX(`J`), 09:00~15:30**, 동일한 완료 분봉 시각을 사용합니다. NXT·통합 시세·시간외 분봉과 섞지 않습니다. `15:30`에는 종가 단일가 체결 분봉을 포함합니다. 요청 시작 때 시각을 고정하므로 종목을 순차 수신하는 동안 기준 시각이 이동하지 않습니다.
- 전 거래일은 KIS 지수 일봉의 실제 거래 기록으로 확인해 주말·휴장일을 건너뜁니다. 최신 모드에서 오늘 거래 기록이 없으면 최근 거래일의 `15:30`으로 전환했다는 안내를 표시합니다. 직접 지정한 휴장일은 거부합니다.
- 개장 시간 변경일·지연 개장 종목 등은 **09:00 분봉이 확인되지 않으면 비교 불가**로 처리합니다. 해당 시각 분봉이 없는 거래정지·신규 상장·무체결·서버 자료 누락도 임의의 0이나 직전 분봉으로 채우지 않습니다. 종가 단일가 대기 구간(`15:20~15:29`)도 실제 분봉이 없으면 선이 끊기고 해당 시각의 비교는 불가합니다.
- 증가액 = 기준일 누적 − 전 거래일 누적. 증가율 = 증가액 ÷ 전 거래일 누적 × 100. 전 거래일 금액이 0원이면 금액 차이는 표시하되 증가율은 `—`입니다.

**분봉·그래프 자료는 파일·DB로 저장하지 않습니다.** 열린 비교 창의 메모리에서만 선택 종목의 두 날짜 자료를 재사용하며, 종목·날짜 변경이나 창 닫기 후 버립니다. 전 거래일 전체 자료를 매분 다시 받지 않고 오늘 새 분봉만 보충합니다. 기존 일봉 캐시·암호화 인증정보는 그대로 사용합니다. 서버 보관 범위(공식 최대 1년) 밖의 분봉은 보장되지 않으며, 재실행하면 API로 다시 받습니다.

분봉 요청은 초당 최대 6회로 제한하고 앱 전체 초당 15회 제한·인증·재시도를 공유합니다. 주말·장외에는 자동 갱신하지 않습니다. 장중 오늘 거래 기록이 없는 휴장일로 확인되면 반복 갱신을 멈추며, 필요하면 조회 버튼으로 다시 확인합니다.

## 부가기능: 외국인·기관 수급

메인 화면 위쪽 **외국인·기관 수급** 버튼은 표에서 선택한 한 종목의 수급 창을 엽니다. 창이 열려 있으면 표에서 다른 종목을 클릭할 때 같은 창이 그 종목으로 바뀝니다. 메인 표·기존 분봉 비교 창은 바뀌지 않습니다.

- **일별 확정 수급**: KIS `주식현재가 투자자`(`FHKST01010900`) 한 번 호출로 최근 거래일들의 외국인·기관계·개인의 매수/매도/순매수 수량과 대금을 받아 표시합니다. 오늘·전일·전전일 표기를 붙이며, 외국인+기관 순매수 합계 열이 있습니다. KIS 안내상 **당일 자료는 장 종료 후 제공**되므로 장중에는 오늘 행이 `집계 전`으로 보이고, 장 종료 후 1분마다 확인해 제공되면 자동으로 채운 뒤 갱신을 멈춥니다.
- **장중 가집계**: KIS `종목별 외인기관 추정가집계`(`HHPTJ04160200`)의 순매수 **수량(주)** 입니다. 증권사 직원이 입력한 누계이며 외국인은 09:30·11:20·13:20·14:30, 기관은 10:00·11:20·13:20·14:30에 입력됩니다. 체결 단위의 실시간 자료가 아니고 금액은 제공되지 않으며 확정값과 다를 수 있습니다. 빈 칸이나 0은 아직 입력 전일 수 있어 최근 입력 요약에서는 제외합니다. 응답에 날짜가 없으므로 오늘이 거래일이고 09:30이 지난 뒤에만 요청합니다.
- **대금 단위**: 투자자 대금 필드는 백만원 단위로 알려져 있으나 같은 응답의 `순매수 대금 ÷ (순매수 수량 × 종가)` 비율로 백만원/원 단위를 교차 확인해 원 단위로 환산합니다. 표본이 부족하면 백만원으로 추정한다고 표시하고, 단위를 확인할 수 없으면 금액을 숨기고 수량만 표시합니다.
- **호출량**: 창이 열려 있는 동안 1분마다 거래일 확인 1회 + 수급 1회(+ 장중 가집계 1회)입니다. 기존 KIS 공용 호출 제한·토큰·재시도를 그대로 사용하며, 받은 자료는 파일·DB로 저장하지 않습니다. 장중과 확정 대기 중에만 자동 갱신하고 21:30 이후에는 새로고침 버튼만 사용합니다.
- 순매수는 매수 − 매도이며 음수는 순매도입니다. 외국인은 등록·비등록 외국인을 합한 값입니다.

## 저장·인증·오류 처리

저장 위치: `%LOCALAPPDATA%\MARS_TOP100`

| 파일 | 용도 |
|---|---|
| `kis_credentials.dpapi` | 저장을 선택한 경우 키·토큰을 비밀번호 + Windows DPAPI로 보호 |
| `kis_token_cooldown.json` | 마지막 토큰 발급 시도 시각만 저장. 키·토큰·비밀번호 없음 |
| `kis_krx_daily_v1.sqlite3` | 어제까지의 KIS 일봉 및 현재 업종 캐시 |
| `kis_*_master.zip` | KIS 공식 종목 목록, 당일 재사용 |
| `kis_mars.log` | 인증정보·원문 서버 응답을 제외한 제한된 오류 로그 |
| `kis_app.lock` | 같은 Windows 사용자의 중복 실행 방지 |

기존 네이버 `history.sqlite3`, `krx_daily.sqlite3` 및 관련 보조 파일·기존 `mars.log`는 시작 시 삭제합니다. 이전 데이터를 가져오거나 네이버로 재접속하는 경로는 없습니다. 오늘 시세는 디스크에 저장하지 않습니다.

저장 파일은 무작위 salt와 scrypt(N=131072, r=8, p=1)로 비밀번호에서 유도한 값을 Windows DPAPI의 추가 보호 값으로 사용합니다. 새 형식은 같은 Windows 계정만으로 복호화할 수 없습니다. 다만 잠금 해제 후에는 API 호출을 위해 키를 메모리에서 사용하므로 악성코드·키로거·메모리 덤프까지 막지는 못합니다. Python 문자열의 완전한 메모리 삭제도 보장하지 않습니다. 이전 형식의 파일은 직접 전환하기 전까지 기존 보호 수준이며, 키 파일을 다른 사람에게 전달하지 마세요.

**PC 키 삭제**는 로컬 파일과 현재 키 사용 상태만 삭제합니다. **토큰 폐기 + PC 키 삭제**는 현재 잠금 해제된 토큰에 대해 한투 `/oauth2/revokeP`를 호출하고 로컬 키를 삭제합니다. HTTP 상태와 응답 코드가 모두 성공일 때만 서버 폐기 완료로 안내합니다. 통신 실패 시에도 로컬 삭제를 진행하며 서버 폐기 미확인을 알립니다. App Key·Secret 자체를 폐기하는 기능은 아니므로 **유출이 의심되면 한투에서 키를 재발급**하세요. 같은 토큰을 사용하는 다른 프로그램도 영향을 받을 수 있습니다.

유효한 토큰은 비밀번호 저장을 선택한 경우에만 재시작 후 잠금 해제하여 재사용하고 만료 2분 전부터 갱신합니다. 토큰 발급은 최소 61초 간격으로 제한하며 모든 병렬 작업이 하나의 인증·호출 제한기를 공유합니다. REST 요청은 응답이 끝날 때까지 직렬화하고 기본 요청 간격을 최소 0.2초로 둡니다. `EGW00201`/HTTP 429가 발생하면 서버 대기시간을 지키고 이후 요청 간격을 최소 0.5초로 늦춥니다. 서버의 일시적 오류에는 제한된 재시도를 적용합니다. 사용자가 다른 KIS 프로그램을 함께 실행하면 동일 App Key의 호출 한도를 공유할 수 있습니다.

인증 실패 시 실전용 키·서비스 신청 상태를 확인하고, 발급 대기 안내가 나오면 표시된 시간 이후 재시도하세요. 네트워크 오류는 연결·서버 점검·PC 시각을 확인하세요. HTTPS 인증서 검증을 유지하고 TLS 1.2 이상으로 직접 연결합니다. 시스템·환경변수의 프록시 설정은 사용하지 않으므로 프록시가 필수인 네트워크에서는 연결되지 않을 수 있습니다.

## 소스 실행 및 Windows EXE 빌드

Windows 10/11 64비트, Tk 포함 Python 3.11 이상을 사용합니다. 이번 검증 환경은 Python 3.14.0, PyInstaller 6.22.3입니다. 런타임 외부 Python 패키지는 없습니다.

```powershell
python mars_app.py

# 빌드 의존성 설치 → 단일 EXE 생성
.\build.ps1
```

스크립트는 프로젝트의 `.venv`를 사용하며 없으면 새로 만듭니다. 시스템 Python 패키지를 변경하지 않습니다. 실행 중인 마스 창을 닫고 빌드하면 현재 폴더의 `마스_TOP100.exe` 하나를 갱신합니다. 배포할 때 이 EXE만 전달하고 개인 설정 폴더는 포함하지 않습니다. `MARS_KIS.spec`에는 사용자 설정·캐시·테스트 모듈을 포함하지 않습니다.

수동 빌드:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --distpath . MARS_KIS.spec
```

이전 네이버 소스 백업·호환 실행 스크립트·중복 EXE·다운로드 참고 자료·임시 빌드 결과는 정리했습니다. 소스 실행 진입점은 `mars_app.py`입니다.

## 코드 구조

- `mars_app.py`: 기존 화면, 설정 창, 메인 스레드에서 결과 표시
- `mars_core.py`: 데이터 모델, 로컬 계산, SQLite, 취소·작업 제어
- `kis_client.py`: 실전 KIS 조회 전용 HTTP, 토큰 수명·공유 속도 제한
- `kis_provider.py`: 공식 종목 목록, 멀티종목 시세, 일봉, 지수 거래일, 업종
- `kis_overseas.py`: 미국(NAS·NYS·AMS) 거래대금·거래량 순위 조회·합산, 달러 표시, 미국 동부시간 계산
- `kis_intraday.py`: 완료 분봉·거래일 결정, 동시간 계산, 메모리 전용 분봉 조회·페이지 처리
- `mars_intraday_ui.py`: 별도 비교 표·정렬·선택 종목의 5분/15분 그래프
- `kis_investor.py`: 외국인·기관 확정 일별 수급과 장중 가집계 조회·파싱·대금 단위 확인
- `mars_investor_ui.py`: 선택 종목의 외국인·기관 수급 창
- `kis_storage.py`: DPAPI, 원자적 파일 교체, 중복 실행 방지, 기존 저장 제거
